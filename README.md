## Featured projects

**[Master-thesis-Cagan](https://github.com/cagandeliktas/Master-thesis-Cagan)**
End-to-end LLM pipeline (Llama 3.1 8B, locally deployed) to extract clinical features (lactate, shock, coma) from 1,618 MIMIC-IV cardiac-arrest discharge summaries via structured JSON prompting. Validated extractions against manual annotations and correlated features with baseline mortality risk via a leakage-aware structured logistic regression trained on first-24-hour ICU data.

Two-tower neural network (TensorFlow/Keras) for user–product affinity prediction on the Sephora dataset. Combined TF-IDF embeddings with SVD, outperforming matrix factorisation and collaborative filtering baselines.
